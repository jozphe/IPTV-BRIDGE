Runtime

Node + TypeScript on Express, deployed as a single Vercel serverless function.

State

No database. Config is LZ-compressed into the manifest URL; hot data lives in a warm-instance TTL cache.

Matching

Title cleaner strips tags & quality; string-similarity ranks candidates with year/episode guards.

Privacy

Your credentials never touch a server datastore — they ride inside the encoded manifest link only.

Efficiency

In-flight de-duplication collapses concurrent identical fetches into one upstream request.

Protocol

Implements the Stremio v3 addon protocol — manifest, catalog, meta and stream resources.

Questions

Do I need a TMDB key?

It's optional but recommended. A free TMDB v3 key powers poster art, ratings and the IMDB/TMDB resolution that lets global search map any title to your IPTV sources.

Where are my credentials stored?

Nowhere on a server. They're LZ-compressed into the manifest URL you generate, so the addon is fully stateless and portable.

Does it work in Nuvio as well as Stremio?

Yes. Both speak the Stremio v3 addon protocol. Use the one-click Stremio install, or paste the manifest URL into Nuvio's add-addon field.

Is hosting really free?

The whole thing runs as one serverless function that fits comfortably in Vercel's free tier. No database, no always-on server.
